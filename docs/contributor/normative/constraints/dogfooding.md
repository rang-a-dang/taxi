# This repository follows Taxi

Every artifact in this repository sits where the taxonomy says it belongs and obeys its frame's contract:
no normative content in descriptive prose, no current-state claims in decisions, no contributor knowledge required to use the project from `docs/consumer/`.
Every documentation directory carries its `AGENTS.md` contract, every kind directory carries its `conventions.md`, and each `AGENTS.md` is paired with a `CLAUDE.md` shim.

A violation is recognizable as any artifact that fails its own frame's test, any directory missing its carrier files, or any statement in the shipped surface that contradicts the taxonomy abstraction.

## Scope

The whole repository, including the README.
The inbox is exempt from frame tests (it is not a frame), but not from the triage-and-clear expectation.
