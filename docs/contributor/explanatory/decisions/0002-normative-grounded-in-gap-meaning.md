title: Name the third frame Normative, ground all frames in gap-meaning, and add the constraint kind
date: 2026-07-05

## Context

The proof of concept named the three frames Explanatory / Descriptive / Directional and justified the set informally ("explains, describes, directs").
Pressed for a closure argument — why exactly three, and no fourth — the frames were re-grounded in one question: what does a gap between the artifact and reality mean?
That grounding exposed a member the old naming served badly: standing rules, which must always hold and are never "done".

## Options considered

- **Keep "Directional".**
  Ruled out: the word leans toward motion and future — "where we're headed" — and a standing rule that is fully satisfied is not somewhere we're headed; it is somewhere we must not leave.
  Directional would fit only if the frame covered future states alone, and it doesn't.
- **Add a fourth frame for standing rules.**
  Ruled out by the closure argument: a persisted claim either isn't about the present, claims the present matches it, or claims the present should match it.
  A rule is the third answer — its gap is a distance (a violation) — so it is a kind within the frame, not a frame.

## Decision

The frames are **Explanatory / Descriptive / Normative**, grounded in the gap question with a closed set of answers: **non-event, contradiction, distance**.
"Normative" means "what should be true", which covers both movement and standing.
The normative frame carries three kinds:

- **target** — existential, one-shot, converts to the descriptive frame when met;
- **constraint** — universal, standing, never converts, and owns its property so the descriptive frame doesn't mirror it;
- **plan** — the route serving a target or constraint.

The distinguishing test between the first two: "if satisfied, is it done?" — yes for a target, no for a constraint.
